# Tableau Workbook

This directory contains the downloaded Tableau packaged workbook (`.twbx`) for the Western PA Lenten Fish Fry Locator.

Live interactive dashboard:

https://public.tableau.com/app/profile/lynn.ruch/viz/WesternPA2026LentenFishFry/WesternPALentFishFryLocator

The Tableau Public version is the easiest way to explore the dashboard interactively. The packaged workbook is included so the Tableau implementation can also be inspected directly.
